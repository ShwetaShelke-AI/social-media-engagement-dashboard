# Social Media Engagement Dashboard

## 📌 Project Overview

The Social Media Engagement Dashboard is a data analytics project created using Python and Power BI.

The project analyzes social media data to understand engagement patterns and presents meaningful insights through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization

## 📊 Dashboard Features

- Engagement Trend Analysis
- Engagement by Content Type
- Engagement by Category
- Likes, Comments and Shares Analysis
- KPI Cards
- Interactive Slicers
- Data Visualization

## 📈 Visualizations

### 1. Engagement Trend
A line chart is used to analyze how engagement changes over time.

### 2. Engagement by Content Type
A bar chart compares engagement for different content types such as Reels, Videos, Images and Shorts.

### 3. Engagement by Category
A donut chart shows engagement distribution across different categories.

### 4. Likes vs Comments vs Shares
A clustered column chart compares likes, comments and shares.

## 💡 Key Insights

- Analyzed social media engagement trends.
- Compared performance of different content types.
- Identified categories with higher engagement.
- Compared likes, comments and shares.
- Created an interactive dashboard for easy data analysis.

## 🎯 Project Objective

The main objective of this project is to analyze social media engagement data and convert it into meaningful visual insights using Python and Power BI.
